# 🌦️ Weather App

## 📌 Project Description
The Weather App is a responsive web application that allows users to search for the current weather of any city. It fetches real-time weather information using the Open-Meteo public API and displays it in a simple and user-friendly interface.

## 🎯 Project Objectives
- Learn DOM manipulation using JavaScript.
- Apply JavaScript ES6+ concepts.
- Understand asynchronous JavaScript using `async/await`.
- Integrate and consume REST APIs.
- Handle API responses and errors.
- Build a responsive and interactive web application.
- Learn Git and GitHub for project hosting.

## ✨ Features
- Search weather by city name.
- Display current temperature in Celsius.
- Show current weather conditions.
- Display humidity percentage.
- Display wind speed in km/h.
- Handle invalid city names and network errors.
- Responsive design for desktop and mobile devices.
- Real-time weather data from a public API.
